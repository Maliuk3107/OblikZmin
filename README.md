# Облік змін

Особистий застосунок для обліку робочих змін, годин і зарплати. Працює в браузері, встановлюється на iPhone та Android як PWA. Українською мовою, зі світлою й темною темами.

## Що вміє

- Додавання зміни з точністю до секунди. Час вводиться цифрами без двокрапок: `07`, `54`, `43`, і курсор сам переходить до наступного поля.
- Кнопка «Початок зміни» з живим лічильником заробітку за сьогодні.
- Ставка, підвищення ставки після N годин, премія (одноразова або повторювана) налаштовуються окремо для кожного місяця. Зміна правил за один місяць не чіпає інші.
- Виплати на картку та залишок до виплати.
- Календар, таблиця, статистика, графіки, історія місяців.
- Експорт у CSV, резервна копія та відновлення з JSON.
- Грошові розрахунки: спочатку сумуються точні секунди й нарахування, і лише підсумок округлюється до копійок.

При першому запуску застосунок просить вказати умови оплати та скільки вже відпрацьовано цього місяця.

## Публікація на GitHub Pages

1. Створіть новий репозиторій на GitHub (краще **Private**, якщо плануєте зберігати там щось особисте. Для безкоштовних акаунтів Pages у приватних репозиторіях може бути недоступний, тоді залишіть Public: у репозиторії немає жодних даних).
2. Завантажте всі файли з цієї папки в корінь репозиторію (Add file → Upload files).
3. Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/(root)** → Save.
4. Через хвилину сайт буде за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

### Встановлення на телефон

- **iPhone:** відкрийте посилання в Safari → «Поділитися» → «На початковий екран».
- **Android:** відкрийте в Chrome → меню → «Встановити застосунок».

## Де зберігаються дані

Тільки в браузері на вашому пристрої (localStorage). На GitHub дані не потрапляють, між пристроями вони не синхронізуються. Робіть резервну копію в Налаштуваннях і не очищуйте дані сайту в браузері без копії. Файли резервних копій не додавайте в репозиторій.

Щоб перенести дані на інший пристрій: «Налаштування» → «Зберегти резервну копію» на першому, «Відновити з копії» на другому.

## Структура

- `index.html`: увесь застосунок в одному файлі (розрахунки між `/*CORE*/` і `/*ENDCORE*/`).
- `sw.js`: офлайн-режим.
- `manifest.webmanifest`, `icon-*.png`: встановлення як застосунку.

## Оновлення після змін у коді

Після зміни `index.html` збільшіть номер версії кешу в `sw.js` (наприклад `worktime-v3` → `worktime-v4`), щоб телефони підхопили нову версію.
